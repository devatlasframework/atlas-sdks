# ATLAS SDK (Python)

Python SDK for the ATLAS /v1 API. Planned: fully typed, ruff-clean.

**No code yet.** It will be generated from `../contract/surface.json` — the same surface, derived
from the same contract, as the TypeScript SDK — and it will run `../scenarios/live.json` as written.
It will have a version of its own, and it will record the contract version it was generated from.
